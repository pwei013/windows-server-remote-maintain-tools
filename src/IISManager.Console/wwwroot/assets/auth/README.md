# 登录页图片来源

- 公司 Logo：从 MKY.Design.V3 的 mky-zero-code-designer 插件所使用的 assets/mookuai-logo.png 直接复制；当前文件 company-logo.png 与原始素材字节一致，385×385。CSS 仅使用原始圆角轮廓裁去白色外角，未重绘 Logo。
- login-servers.png：内置 Image Gen 依据已选方案 1 生成透明服务器插图，并降低亮度；实际 1495×1052 RGBA，显示约512×360。保留三台服务器、四窗格与代码面板，无文字或品牌内容。生成工具未遵循精确1024×720画布，但比例近似且显示分辨率充足。
- 登录图标：Microsoft Fluent UI System Icons 官方 Person、Lock Closed、Eye、Eye Off 的原始24px regular SVG；来源及MIT许可位于 ../fluent。

最终插图为本目录的 login-servers.png。完整生成提示词保存在本地设计记录中，不随源码仓库交付。
