## 使用边界

配置维护要求目标站点、全部原关联应用池和新关联应用池已经停止；不会代为启停、创建物理目录、复制文件、调整 ACL 或导入证书。共享 TLS 和无法安全保留的高级 SSL 策略会拒绝更改。详见 [维护说明](site-maintenance.md)。

诊断首次 CPU 样本、不可访问模块和超限采样明确显示未知/不可用/部分结果。它不返回原始事件正文、请求 URL、查询参数、Cookie、进程命令行或环境变量。详见 [诊断说明](diagnostics.md)。

新增 Agent 的通信设置保存并人工重启 Console 后生效；授权策略立即生效。默认保留原有用户的服务器管理行为，接入与授权设置仅限明确登记的管理员；启用严格模式后未授权服务器不可见。已有健康检查不能迁移服务器，需由有权限的操作员删除旧项并在目标服务器新建。详见 [接入与权限说明](administration.md)。

网页接入状态由实际 Windows Console 服务身份使用 DPAPI CurrentUser 保护，默认存于程序目录外的受限 ProgramData 实例目录，不会自动搬迁旧 appsettings 中的凭据。更换身份、程序根路径或数据目录前须保留原状态并按运维流程迁移；无法解密时不能重置。生产没有明文回退。首位管理员需由操作员登记实际 AppId/UserId。

基线位于 `Console.Monitoring.DataDirectory/configuration-baselines`。保存需要配置权限及当前指纹/版本，超过 8 MiB 在写入前拒绝；持久化配置逐层校验字段白名单。文件损坏或外部修改后停止相关写入，保存不是回滚功能。基线含资源名称、目录和域名，导出按内部运维资料保管。

历史缓存减少反序列化；每次查询仍读取并哈希校验全部账本文件，损坏、删除及范围外异常不会被筛选隐藏。大历史量仍有磁盘成本。CSV 不含完整请求、凭据或操作参数；超过上限须缩小筛选范围。

## 可选配置

默认监控配置可沿用。`Console.Monitoring` 的 `OverviewConcurrency` 范围 1–16、默认 4；`OverviewTimeoutSeconds` 范围 1–30、默认 5；`OverviewCacheSeconds` 范围 5–120、默认 15。

首次启用接入管理，在现有配置中合并 `Console.Administration.BootstrapAdministrators`，每项为实际 `appId` 和不可变 `userId`，不能用显示姓名代替。可选 `DataDirectory` 必须位于程序目录外并限制权限。生产不得启用 `AllowDevelopmentPlaintext`。身份、用户配置文件和配置优先级见接入说明。
