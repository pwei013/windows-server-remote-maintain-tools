本文保留 20261003 首版证据。20261004 先新增无需证书的 HTTP 加来源白名单模式，当前 `intranet` 安装包再新增默认自动内网来源访问，无需填写管理来源 IP/CIDR。原首版及上一版的自测数量不能替代当前版本验证；新安装包的构建、自测与模拟联调结果见 [安装器验证记录](installer-validation.md)。HTTP 模式不改变 IIS 站点 HTTPS 证书/绑定验收要求。

验证日期：2026-10-03。开发环境为 macOS arm64，SDK 10.0.401，运行时 10.0.12。

- 独立的本机可移植 Release 构建通过，23 项自测通过。覆盖编号去重与冲突、截止时间、配置指纹变化、持久化先于写入、串行执行、重启后未知状态、存储损坏拒写、局部修改及绑定校验。

- JavaScript 语法、开发脚本 Bash 语法、配置 JSON 与 NLog XML 检查通过。
- 本次启动的测试进程已退出，临时任务状态和测试目录已清理。

## 验证范围

模拟 Agent 不接触真实 IIS，也不修改 Windows 配置、目录权限或证书存储。本次没有 Windows Server 环境，因此 Windows 服务、IIS 原生 API、HTTP.sys/TCP 监听读取、目录身份与 ACL、双向证书认证、实际 HTTPS 握手和业务访问尚未实机验收。

站点证书预检查读取已有证书的私钥关联、有效期、主机名称和 EKU；不证明私钥实际可用，也未检查该站点证书的完整信任链与在线撤销状态。HTTPS 模式下控制台到 Agent 的连接另行执行 TLS 名称、证书链、撤销和指纹校验；新 HTTP 模式使用独立访问令牌与实际来源网络校验，无 TLS。当前新装 `PrivateNetwork` 自动允许内网来源；旧 `Allowlist` 安装更新后保留原限制。

下一步按 [Windows 运行与验收](windows-operations.md) 在测试服务器人工验收；本地构建成功不能替代该步骤。
